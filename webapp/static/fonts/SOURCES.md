# Font provenance

`geist-sans.woff2` and `geist-mono.woff2` are unmodified variable webfonts downloaded from the official Vercel Geist repository during the Geist typography change.

- Repository: https://github.com/vercel/geist-font
- Sans source: `fonts/Geist/webfonts/Geist[wght].woff2`
- Mono source: `fonts/GeistMono/webfonts/GeistMono[wght].woff2`
- Upstream license: SIL Open Font License 1.1; see `OFL.txt`.
- The accompanying license was retrieved from upstream commit `2e554ff2ea3979b63afe770af6424eb8b9490a74`.

The original downloads used the repository's `main` branch. This provenance record does not assert an immutable source commit for those earlier downloads.
